# Project rubric

Score each dimension 0 (missing), 1 (partial), or 2 (demonstrated). A passing reference test alone is insufficient.

| Dimension | Evidence for 2 |
|---|---|
| Contract | Inputs, outputs and errors are explicit and tested |
| Correctness | Normal, boundary and failure cases pass |
| Evaluation | Frozen cases, metric denominator and failure slices are reported |
| Safety | Tenant scope, untrusted content and effect controls are enforced in code |
| Portability | Offline run works without secrets, account or GPU |
| Explanation | Learner explains a trade-off and an unverified boundary |

A project is complete at 10/12 or above with no zero in correctness or safety, plus the required deliverables in its README. Reviewers record evidence, not impressions.
