# Offline foundations demonstrations

Run from this directory with `python day04_offline_budget.py`, `python day05_vectors.py`, and `python day06_attention.py`. On macOS/Linux use `python3` if needed; on Windows use `py -3` if needed. These screened demonstrations came from the source archive. Word splitting is not a production tokenizer, hand-made vectors are not learned embeddings, and the attention example is not a complete transformer. Explain one failure of each analogy before moving to a live model.
