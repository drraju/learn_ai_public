# Concept guide

The portfolio artifact should connect requirements to evidence. For each requirement, point to code, a normal test, a failure test and a limitation. Run the frozen case set from P6 and explain its denominator. Show both a successful investigation and an abstention or denial. A diagram should mark data, identity and tool trust boundaries, not only component names.

A defensible design states why it chose lexical retrieval first, why tool permission is enforced outside a model, and what the two-role workflow adds or fails to add. Include the threat model, runbook, release manifest and a short record of unverified provider paths. Passing a local reference suite does not establish production readiness; explain the remaining identity, durability, scale, monitoring and rights work.

**Decision to defend:** Which single change would most reduce the gap between this local reference and a deployable service, and how would you test it?
